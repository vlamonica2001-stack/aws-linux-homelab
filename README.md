# AWS Linux Homelab

A self-managed Linux server built on AWS EC2, set up and hardened from scratch to build practical sysadmin and IT support skills for my career.

## Why I built this
I wanted hands-on experience with the kind of work an IT support or sysadmin role actually involves — not just theory. Everything here was configured, broken, and fixed by me on a live server.

## What's included
- **EC2 instance setup** — provisioned and configured a Linux server on AWS
- **SSH hardening** — disabled root login, restricted access to a specific IP, key-based authentication only
- **Nginx** — installed and configured as a web server
- **MariaDB** — installed, secured, and used to build a small database
- **Log analysis** — investigated server access logs using SQL to identify patterns and anomalies (including spotting automated scanner traffic)

## Skills demonstrated
- Linux command line and system administration
- Server security fundamentals (SSH hardening, access control, principle of least privilege)
- Web server configuration (nginx)
- Database administration (MariaDB) and SQL querying
- Log analysis and identifying anomalous/malicious traffic patterns
- Version control with Git and GitHub
